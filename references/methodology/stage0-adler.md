# 阶段 0 — Adler 整书理解（分析阅读法）

借鉴 Mortimer Adler《如何阅读一本书》的分析阅读四步，对整份内容做结构化理解。

## 四步

### 1. 结构（Structural）
- 这本书/视频解决什么核心问题？
- 整体由哪几大部分构成？列出骨架（章节/模块/时间段）。
- 作者用什么顺序展开论证？

### 2. 解释（Interpretive）
- 作者用了哪些关键概念？彼此如何关联？
- 核心主张/命题是什么（一句话能说清吗）？
- 哪些论点最反直觉、最值得保留？

### 3. 批判（Critical）
- 作者的盲点、隐含假设、适用边界在哪里？
- 哪些结论依赖于特定前提（行业/时代/人群）？
- 哪些主张你存疑、需标 needs_review？

### 4. 应用（Applied）
- 这些方法论在哪些真实工作/决策场景可被调用？
- 哪些适合做独立 skill，哪些只适合做背景/候选？

## 产出

按 `references/templates/BOOK_OVERVIEW.md` 填充，写入 `books/<slug>/BOOK_OVERVIEW.md`。
展示给用户确认：「骨架我理解对了吗？有没有你希望重点突出的方向？」得到确认再进阶段 1。

## 长文本处理

超出单次阅读上下文时，分块阅读后汇总骨架；保留每块对应的原文位置（页码/时间戳/章节），供阶段 1 提取器回溯佐证。
